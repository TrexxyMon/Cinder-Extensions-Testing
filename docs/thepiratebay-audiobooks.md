# The Pirate Bay Audiobooks

This extension is now maintained in the public
[Cinder Reader Extensions repository](https://github.com/TrexxyMon/Cinder-Extensions).
See its [setup and validation documentation](https://github.com/TrexxyMon/Cinder-Extensions/blob/main/docs/thepiratebay-audiobooks.md).

Add the [public repository](https://raw.githubusercontent.com/TrexxyMon/Cinder-Extensions/main/repo.json),
refresh both repositories, and update to `0.1.3-cinder` without uninstalling.
The extension ID and settings keys are unchanged. The old private script is
retained only for cached manifests and older installations.
